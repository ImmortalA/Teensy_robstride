# Teensy-Spine-Board

Teensy 4.1 Ethernet-UDP to CAN bus bridge for Robostride O2 actuators (extended 29-bit CAN protocol).  

# Files

## communication_PC_Teensy

- Working code for communicating between 1 teensy board and 1 robstride o2

## enable_motor_only

- Working code for enable motor from teensy board
